# GPS Speed Dial

A full-screen, installable GPS speedometer PWA designed for Android and windshield HUD use.

## Features
- Analog 0–120 MPH sports-car-style dial
- Center digital MPH readout
- Smooth red needle with responsive digital speed
- High-accuracy browser GPS
- One-tap mirrored windshield HUD mode
- Landscape/full-screen presentation
- Offline PWA support
- No location storage or server-side tracking

## GitHub Pages
This repository includes a GitHub Pages Actions workflow. In **Settings → Pages**, set **Source** to **GitHub Actions** if it is not already selected. The deployed URL is expected to be:

https://newnetmp3.github.io/gps-speed-dial/

## Android
Open the Pages URL in Chrome on Android and use **Add to Home screen / Install app**. Location permission is required for GPS speed.
